# 🍣 ROGE Sushi
![ROGE Sushi Preview](preview.png)

ROGE Sushi is a modern and responsive Japanese restaurant website designed to provide an elegant and intuitive digital experience.

The project was developed with a focus on modern interface design, responsiveness, usability, and interactive features.

## 🌐 Live Website

👉 https://rogesushioficial.netlify.app/

## ✨ Features

- 🍱 Interactive digital menu
- 🛒 Shopping cart
- 🔎 Product search and filtering
- 🌐 Portuguese and English language support
- 🌙 Light and dark themes
- 📱 Fully responsive design
- 💻 Modern and intuitive interface
- ⚡ Fast and lightweight experience

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Netlify

## 📱 Responsive Design

The interface was designed to adapt to different screen sizes, providing a consistent experience on desktop, tablet, and mobile devices.

## 🎯 About the Project

ROGE Sushi was created as a front-end development project focused on applying concepts of web development, responsive design, user experience, and JavaScript interactivity.
